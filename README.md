
# Sistema de Controle de Estoque e Vendas – Padaria Pão Quentinho

Projeto desenvolvido para a Atividade 3 – Projeto de Software.

## Descrição

O sistema foi desenvolvido para auxiliar no controle de estoque e no registro de vendas de uma padaria, facilitando a organização dos produtos e reduzindo erros no controle manual.

## Funcionalidades

- Cadastro de produtos.
- Consulta de estoque.
- Registro de vendas.
- Baixa automática do estoque após uma venda.
- Alerta de estoque baixo.
- Histórico de vendas.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML

## Como executar o projeto

1. Instale o Python.
2. Instale o Flask com o comando:

   `python -m pip install flask`

3. Abra o terminal na pasta do projeto.
4. Execute:

   `python app.py`

5. Acesse no navegador:

   `http://127.0.0.1:5000`

## Objetivo

O projeto busca melhorar o controle de produtos e vendas da padaria, contribuindo para uma gestão mais organizada e para a redução do desperdício de alimentos.
